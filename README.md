# Орбита — дисперсия углов планет

Интерактивный график углового разброса восьми планет Солнечной системы за период
**±10 000 лет** вокруг выбранного момента. Инструмент считает четыре метрики,
умеет увеличивать масштаб до шага в несколько минут и находит момент, когда планеты
были ближе всего к «параду» в смысле выбранной метрики.

## Возможности

- **Четыре метрики** (переключатель в интерфейсе):
  - **σ²** — дисперсия углового отклонения от циркулярного среднего, град²;
  - **σ** — среднеквадратичное отклонение, град;
  - **½-норма** — `(Σ √|δᵢ|)²`, град;
  - **D** — евклидово расстояние между средним вектором положения планет и Солнцем, а.е.
- **Масштаб**: пресеты ±10 000 / 1000 / 100 / 10 лет / 1 год / 1 месяц, кнопки `+`/`−`,
  протяжка мышью по графику, клик по миникарте. Шаг подбирается автоматически
  (от 5 лет до 15 минут), число точек ограничено бюджетом 8 000.
- **Поиск минимума** выбранной метрики: глобальный скан окна, затем уточнение до минут.
  Найденный момент отмечается на графике, открывается кнопкой «Открыть день».
- **Режимы графика**: «Система» (суммарная метрика) и «По планетам» (вклад каждой планеты;
  доступно для угловых метрик).
- **Снимок системы** с положениями планет и карточки отклонений по планетам.
- **Экспорт CSV** текущего окна со всеми долготами, отклонениями и метриками.

## Модель

Гелиоцентрические долготы считаются по элементам **JPL / Standish**
(*Keplerian Elements for Approximate Positions of the Major Planets*):

- **1800–2050** — таблица 1 JPL;
- **−3000…3000** — таблица 2a и периодические поправки 2b для внешних планет;
- вне этих интервалов результаты помечаются как **экстраполяция**.

Уравнение Кеплера решается методом Ньютона, орбита переводится в эклиптику J2000.
Среднее направление — циркулярное: `λ̄ = atan2(Σ sin λᵢ, Σ cos λᵢ)`,
отклонения `δᵢ = wrap(λᵢ − λ̄)`.

Модель **двухтельная**: планеты не взаимодействуют друг с другом, поэтому долгосрочная
точность ограничена. Для точных дат используйте JPL DE440/DE441 или VSOP87.
Слово «парад» здесь статистическое (сколько планет попало в ±30° от среднего)
и не означает видимого сближения на небе.

Подробности и источники есть в разделах «Как построена модель» и «Источники»
внутри приложения.

## Технологии

React 19 · TypeScript · Vite 7 · Tailwind CSS 4 · SVG (без внешних графических библиотек).
Сборка через `vite-plugin-singlefile` создаёт **один HTML-файл** со всем кодом и стилями.

## Быстрый старт

проект можно открыть по ссылке: https://01a19647-cb14-76a4-9c44-aaf69ee1d315.arena.site/

### Требования

- **Node.js 20 или новее** (проверка: `node -v`). Вместе с Node ставится `npm`.
- Для шрифтов из интернета нужен доступ в сеть; без него приложение работает, но
  шрифты будут заменены системными.

### Запуск в режиме разработки

```bash
npm install
npm run dev
```

Откройте адрес, который выведет команда (обычно `http://localhost:5173`).

### Сборка готового HTML

```bash
npm install
npm run build
```

Результат: файл **`dist/index.html`** (около 350 КБ). Его можно:

- открыть двойным кликом в любом современном браузере — сервер не нужен;
- отправить по почте или выложить на любой хостинг статических файлов;
- проверить локально командой `npm run preview`.

### Просмотр собранной версии

```bash
npm run preview
```

## Загрузка проекта на GitHub

### Вариант 1. Через командную строку git

1. Установите [git](https://git-scm.com/downloads) и зарегистрируйтесь на
   [github.com](https://github.com).
2. Создайте **пустой** репозиторий: нажмите **New** на github.com, задайте имя
   (например `orbita`), **не** ставьте галочки «Add a README», «.gitignore» и «license» —
   файлы уже есть в проекте.
3. В папке проекта выполните:

   ```bash
   git init
   git add .
   git commit -m "Initial commit: Орбита — дисперсия углов планет"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/orbita.git
   git push -u origin main
   ```

   Замените `<ваш-логин>` и имя репозитория на свои.

4. При первом `git push` git запросит авторизацию. Пароль от аккаунта больше не
   принимается — используйте **Personal Access Token** (GitHub → Settings →
   Developer settings → Personal access tokens) с правом `repo`, либо войдите через
   [GitHub CLI](https://cli.github.com/): `gh auth login`.

### Вариант 2. Через GitHub CLI одной командой

```bash
gh repo create orbita --public --source=. --remote=origin --push
```

### Вариант 3. Через браузер (без git)

1. На github.com нажмите **New** и создайте пустой репозиторий.
2. Нажмите **uploading an existing file** и перетащите содержимое папки проекта.
   **Не загружайте** папки `node_modules` и `dist` — они исключены в `.gitignore`,
   но при ручной загрузке их легко добавить случайно.
3. Нажмите **Commit changes**.

## Публикация сайта на GitHub Pages

В проекте уже есть workflow `.github/workflows/deploy.yml`, который при каждом пуше
в ветку `main` собирает приложение и публикует его.

1. Откройте репозиторий → **Settings** → **Pages**.
2. В разделе **Build and deployment** в поле **Source** выберите **GitHub Actions**.
3. Сделайте любой пуш в `main` (или откройте вкладку **Actions** и запустите
   **Deploy to GitHub Pages** вручную через **Run workflow**).
4. Через минуту-две сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/orbita/`. Ссылка также появится в разделе
   **Environments → github-pages** и в выводе workflow.

Если ветка называется не `main`, поправьте строку `branches: [main]` в
`.github/workflows/deploy.yml`.
