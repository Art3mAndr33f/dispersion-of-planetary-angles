# dispersion-of-planetary-angles
Гелиоцентрические долготы восьми планет за 20 000 лет. Для каждого момента находим циркулярное среднее направление и измеряем, насколько сильно планеты от него расходятся. Ищем и день наименьшей дисперсии — ближайший к «параду планет», с масштабом от тысячелетий до одного дня.
